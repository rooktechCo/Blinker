
# Blinker

Blinker is a lightweight, cross-platform text editor built with Java Swing. It provides a clean and intuitive GUI for creating, editing, and saving text files on macOS, Windows, and Linux.



## Features
- Create, edit, and save text files with ease
- "Save" and "Save As" functionality
- Robust error handling for file operations
- Cross-platform support: macOS, Windows, and Linux

## Requirements
- **Java**: Version 21 or higher
- **Maven**: Version 3.9 or higher
- **IDE**: Any Java IDE (e.g., IntelliJ IDEA, Eclipse, or VS Code with Java extensions)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Mwiza-Sichinga/Blinker.git
   cd Blinker
   ```
2. Build the project using Maven:
   ```bash
   mvn clean compile
   ```
3. Run the application:
   ```bash
   mvn exec:java -Dexec.mainClass="com.rooktechnologies.blinker.Main" 
  

## Installation
1. Launch the application using the command above or through your IDE.
2. Use the GUI to:
   - Create a new text file
   - Open an existing file
   - Edit and save your changes
   - Use "Save As" to save to a new file
3. Error messages will display if file operations fail (e.g., permission issues).
